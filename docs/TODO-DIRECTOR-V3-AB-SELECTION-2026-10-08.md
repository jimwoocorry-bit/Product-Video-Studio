# Product Video Studio 待办：Director V3 A/B 方案评估与采用

- 记录日期：2026-10-08
- 状态：待设计与开发（仅登记需求，尚未实施）
- 来源：Tonemay Q8 一键成片流程实测反馈
- 问题：现有「Director V3 A/B 影子预演」能够显示旧版与新版剧本、分镜、Seedance 提示词差异，但缺乏“选择/采用更好方案”的正式操作，预演结果不能直接用于后续一键成片。

## 需要改进的功能

1. A/B 方案并列对比：剧情吸引力、产品展示准确性、AI 可生成性、人物与场景连续性、镜头节奏、声音设计、Prompt 质量、预计生成开销与风险，分项说明优缺点；不捏造视频实际成片效果。
2. 允许选择 A（保留当前正式方案）、B（采用 Director V3 预演方案），可选支持融合 A/B 优点形成 C（需重新校验）。
3. 增加「AI 推荐方案」及理由；用户最终拍板，不把评分/推荐自动当成确认。
4. 在用户点击“采用 B / C”前，预览修改范围、变更的剧情/镜头数/提示词、版本和下游影响。
5. 采用时必须通过既有 Script QA、导演分镜、Prompt/Preflight 校验；正式写入后续创作链（不能只修改预览 HTML），并保留历史版本和可回退路径。
6. 使用已有已确认产品事实、角色/场景资产，不因切换方案自动重做或再次扣费。新版方案使旧的 Preflight 和付费确认失效，禁止未得到本轮明确授权就提交 Seedance。
7. 提供回归测试：选 A 不产生变化；采用 B/C 校验和版本更新正确；失败不覆盖正式方案；已有资产、人工确认、支付权限不被篡改；不可将影子测试误称为真实视频 A/B 效果验证。
