| 目标/用户情况 | 入口 | 必要节点 | 可选分支 | 必须人工确认/付费门禁 | 失败恢复/下一步出口 |
|---|---|---|---|---|---|
| 1. 从零制作产品宣传片 | 项目 → 产品 → smart | 产品事实 → 创意 → 资产规划 → 脚本/导演 → Preflight → 视频 → 审片 → Timeline → 成片 | 研究、参考、BGM、本地音频 | 事实、创意、AI 新资产、资产/视频费用、低置信镜头、最终成片 | 当前 Run 的具体待处理动作，不回到起点 |

| 4. 剧情/Director V3 多镜头制作 | smart | 角色/场景固定资产 → 脚本 QA → Clip Contract/Prompt V3 → 视频 | A/B 影子预演 | 资产费用、新视频费用及角色图看图确认 | 保留单个角色/场景依赖，按资产节点原地恢复 |
| 5. 只生成单片段 | single-video | 材料/模型时长能力 → 明确付费 → 生成 → 查看 | 单独参考 | 每次新付费提交必须单独批准 | 与完整 smart 区分，完成即回单片段历史 |

| 7. 制作资产失败或远端未知 | smart 资产面板 | 审查提交编号/远端结果 → 可用时续取 → 单资产修复 | 改 Prompt / 重新生成 | 未知禁止重复付费提交；重生需新确认 | 原 Run / 原资产 key；其他独立资产继续 |
| 8. 现有片段重剪 | timeline / auto-edit | 已采用产物 → Timeline → 音轨字幕 → 确认/渲染 → Final | 音频、手动转场、遮罩 | 不改原生成或事实，成片人工确认 | 保留旧 Timeline 版本，失败回到剪辑 |

| 10. 发布后运营 | /projects/:id/douyin | 确认作品绑定 → 指标/评论/复盘 | 采集同步、AI 分类 | 人工绑定单个作品；评论发布逐条确认 | 账号/运营连接异常保留历史，禁止假装实时 |

## 3. 质量与实现评审（按职责检查）

- **产品/UX**：以「我这次要做什么」选择独立业务目标；同一任务只显示一个最紧迫的下一动作，不用旧项目级导航覆盖真实任务状态；专家编辑入口必须保留。
- **后端/状态**：读数据无副作用；`SmartRun` 优先选择未关闭且最近更新的 Run；`Project` / 已确认 Final 只作为兜底，不同状态不得出现互相矛盾的“下一步”。
- **前端/交互**：待审核外部页使用项目 + run 精确回程地址，服务端验证项目归属，不能信任第三方任意 returnTo URL；按钮中文、状态明确。
- **生成/安全**：审核与“再次提交付费”分离；镜头重做不作废其他镜头链；不在本轮重构隐式修复已有 Preflight 事故，也不篡改审批 DB。
- **QA**：至少覆盖全部 21 个 Run status、无 Run、多个 Run、旧已完成 Run、被阻塞 Run、无产品资料及项目已发布等分支；验证 GET 路由不产生数据库写、无任何付费/发布命令。

## 4. W1 只读恢复决策接口建议

建议新增纯函数 `resolveProductionNextAction`：

- 输入：`{project, productInput?, productTruthStatus?, runs}` 等现有快照；
- 输出：`{projectId, runId?, stage, status, label, action:{label,href,kind}, returnHref, reason, requiresExplicitConsent, source}`；
- 归属：对 SmartRun 自身 `projectId` 做校验；自动选择最新有效任务，防止多个任务交叉；
- 状态：`USER_ACTION / IN_PROGRESS / BLOCKED / DONE` 等 UI 状态，符合等待动作映射，**不是新的生成状态机**；
- `GET /api/projects/:projectId/workflow` 只读返回上述解析结果；原路由不删除；
- UI 智能生成顶部显示“当前阶段、当前要做、下一步”，通过锚点或受控项目内链接跳转；从外部审核页可明确返回原 Run（本期对兼容页面做小切片）。

W1 不擅自做：自动通过审片、自动生成新素材、自动确认新费用、导入未经确认的研究事实或外部账号操作。
